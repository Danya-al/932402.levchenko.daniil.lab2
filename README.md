## Описание

Оформление страницы из ЛР №1 средствами CSS: внешний файл стилей, переменные, псевдоклассы и псевдоэлементы.

## Три способа подключения стилей

- **Внешний файл** `style.css` — основные стили страницы
- **Внутренний блок** `<style>` в `<head>` — размер и межстрочный интервал заголовков
- **Inline** — `object-fit: cover` для изображения в шапке

## Реализовано по варианту

- Цветовые переменные в `:root`: кремовый основной, терракотовый акцент
- Карточки проектов со скруглёнными углами и размытием фона при наведении через `filter: blur()` на псевдоэлементе `::before`
- Жёлтая обводка полей формы при `:focus`

## Структура

- `index.html` — разметка страницы
- `style.css` — внешние стили
- `images/avatar.jpg` — логотип блога
